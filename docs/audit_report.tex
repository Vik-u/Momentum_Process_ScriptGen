\section{Scope}
Audit of the Momentum\_db workflow assets under \texttt{viku/PlayGround/Momentum\_db}, focusing on deterministic generation of Momentum-compatible process files and documentation.

\section{Key Assets}
\begin{itemize}[leftmargin=*]
  \item \textbf{Data sources}: \texttt{Momentum\_db1.txt}, \texttt{Momentum\_db2.txt}, \texttt{inventory\_containers.yaml}
  \item \textbf{Catalog}: \texttt{step\_catalog.json} (+ split files under \texttt{catalog\_parts/})
  \item \textbf{Docs}: \texttt{docs/step\_reference.md} (static reference)
  \item \textbf{Generators}:
    \begin{itemize}[leftmargin=*]
      \item \texttt{generate\_step\_catalog.py} --- builds deterministic catalog with params, defaults, ranges, containers
      \item \texttt{generate\_process\_file.py} --- renders Momentum process text from ordered steps
      \item \texttt{generate\_docs.py} --- emits static Markdown docs from catalog
      \item \texttt{deterministic\_agent.py} --- CLI “agent” (list/describe/build)
      \item \texttt{streamlit\_app.py}, \texttt{gradio\_app.py} --- interactive UIs (optional)
    \end{itemize}
\end{itemize}

\section{Deterministic Data Model}
\begin{itemize}[leftmargin=*]
  \item \textbf{Steps}: \texttt{device $\to$ operation $\to$ \{parameters (ordered), parameters\_meta, containers\}}
  \item \textbf{parameters\_meta}: inferred type (boolean/number/time/string), default, observed values, min/max (where applicable)
  \item \textbf{Containers}: list of \{container, lid\_state, location\}; all entries retained per step
\end{itemize}

\section{Current Workflows}
\begin{itemize}[leftmargin=*]
  \item Catalog build: \texttt{python generate\_step\_catalog.py --inputs Momentum\_db1.txt Momentum\_db2.txt --inventory inventory\_containers.yaml --output step\_catalog.json --split-dir catalog\_parts}
  \item Docs build: \texttt{python generate\_docs.py --catalog step\_catalog.json --output docs/step\_reference.md}
  \item CLI build (example):
\begin{verbatim}
python deterministic_agent.py build-process \
  --base Momentum_db1.txt \
  --process-name Demo_CLI_Agent \
  --steps "B_XPeel:Remove Seal;AdhereTime=2.5|A_Combi_Shelf:Dispense;DispenseVolume=50;PlateType=96 standard (15mm);PrimeEnabled=No" \
  --output demo_agent_process.txt
\end{verbatim}
  \item Step inspection: \texttt{python deterministic\_agent.py describe-step --device B\_XPeel --op "Remove Seal"}
\end{itemize}

\section{Fixed Risks / Gaps}
\begin{itemize}[leftmargin=*]
  \item Param parsing now captures mixed quoted/unquoted values (no drops).
  \item Parameter defaults derived deterministically (sorted observed values).
  \item All containers per step are emitted (no silent collapse to first).
  \item Single quotes in values are escaped when writing Momentum text.
  \item Streamlit base file selection now allows arbitrary base path input.
\end{itemize}

\section{Residual Considerations}
\begin{itemize}[leftmargin=*]
  \item PDF rendering not bundled (no \texttt{pdflatex} on host); compile this \LaTeX{} externally if a PDF is needed.
  \item Catalog accuracy depends on source DBs; re-run catalog after DB changes.
  \item Validation: steps with \texttt{<FILL>} still require user-supplied values; add a validator step to enforce none remain.
\end{itemize}

\section{How to Use (Deterministic Agent)}
\begin{itemize}[leftmargin=*]
  \item \texttt{list-devices}, \texttt{list-operations --device DEV}: discover capability set.
  \item \texttt{describe-step --device DEV --op OP}: retrieve required params/defaults/containers.
  \item \texttt{build-process --base FILE --process-name NAME --steps "..."}: render Momentum process text with invariant header.
\end{itemize}

\section{Testing / Validation}
\begin{itemize}[leftmargin=*]
  \item \texttt{python -m py\_compile *.py} (passing)
  \item \texttt{curl http://127.0.0.1:PORT} used to confirm UI process responsiveness when applicable.
\end{itemize}

\section{Recommendations}
\begin{itemize}[leftmargin=*]
  \item Add a \texttt{validate} subcommand to fail if any \texttt{<FILL>} remain or if containers are not in \texttt{inventory\_containers.yaml}.
  \item Package CLI and docs generation into a simple \texttt{make} target for reproducibility.
  \item Optionally export \texttt{step\_reference.md} to a static site (mkdocs) for easy browsing.
\end{itemize}
